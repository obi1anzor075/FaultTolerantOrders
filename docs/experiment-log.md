## Опыт 1 — сбой после сохранения заказа, до публикации события

**Проверяемый инвариант:** сохранённый заказ должен иметь доставляемое событие. Исходная версия системы этот инвариант не обеспечивает.

| Показатель | До запроса | После восстановления |
|---|---:|---:|
| Число заказов | Не измерено | Не измерено |
| Число уведомлений | Не измерено | Не измерено |
| Число сообщений в очереди | Не измерено | Не измерено |

- Дата: 12 октября 2026 года. Запуск выполнен пользователем на другом компьютере.
- Версия кода: локальная версия при анализе — `982dc98`. Ревизия и идентификаторы образов на компьютере запуска не зафиксированы в переданном логе.
- Команда и параметры запроса: точное тело запроса и команда клиента не представлены. Маркер инъекции соответствует ветке `X-Fault-After-Commit: true` в текущем API.
- Контрольный заказ: `9346d211-b010-4b21-a71d-9fcc795a0476`.
- Заказ аварийного запроса: `ad665171-d54f-4111-99bc-a9e556fd0be0`.
- Исходные логи: [2026-10-12-baseline.txt](experiments/2026-10-12-baseline.txt), точная копия переданного `experiment-1.log` (796 строк).
- SHA-256 исходного файла: `2122548ADF944CFFD954642F3A98DF12255443059E49D026110116D2F6F6854C`.

### Подтверждённое состояние аварийного заказа после восстановления

Пользователь подтвердил результат контрольных команд: заказ получен через `GET /api/orders/{id}`, SQL-проверка Notifications для этого OrderId вернула 0. Источник этого подтверждения — сообщение пользователя в чате; исходный вывод HTTP и SQL отдельно не приложен.

| Проверка для OrderId `ad665171-d54f-4111-99bc-a9e556fd0be0` | Результат |
|---|---|
| Заказ существует после перезапуска | Да, подтверждено пользователем |
| Число уведомлений для этого заказа | 0, подтверждено пользователем |

Общие числа строк в таблицах и состояние очереди остаются неизмеренными; подтверждение относится только к указанному заказу.

От маркера падения до сообщения о прослушивании HTTP-порта прошло **17,543 секунды**. Это интервал восстановления слушателя API в одном запуске, а не измерение полной готовности всех операций и не среднее время восстановления.

### Результаты и ограничения

- Контрольная цепочка «заказ → RabbitMQ → уведомление» сработала: в логе есть одна успешная обработка контрольного заказа.
- Инъекция сбоя достигла нужной точки. В текущем коде `Environment.FailFast` расположен после завершившегося `SaveChangesAsync`, до создания и публикации события. Лог содержит соответствующий маркер с идентификатором заказа.
- Во всём переданном логе есть две команды INSERT в Orders, одна команда INSERT в Notifications и один маркер успешной обработки уведомления. Число SQL-команд не заменяет измерение итоговых строк в базе.
- Записи об уведомлении для аварийного заказа в переданных логах нет. Последующая проверка, подтверждённая пользователем, установила, что заказ существует после восстановления, а уведомлений для него — 0.
- API перезапустился. Сам перезапуск не является свидетельством восстановления потерянного события.
- Сообщение об отсутствующей `libgssapi_krb5.so.2` не остановило приложения в этом запуске: после него видны успешные SQL-операции и контрольная обработка. Причина намеренного падения зафиксирована отдельным маркером `FailFast`.

### Команды для повторной проверки состояния

Команды для проверки состояния на компьютере запуска в папке Compose. При повторном запуске следует сохранить вывод вместе с логами.

```powershell
@'
SELECT "Id", "Total", "CreatedAt"
FROM "Orders"
WHERE "Id" = 'ad665171-d54f-4111-99bc-a9e556fd0be0';
'@ | docker compose exec -T order-db psql -U lab -d orders

@'
SELECT COUNT(*) AS notifications_for_failed_order
FROM "Notifications"
WHERE "OrderId" = 'ad665171-d54f-4111-99bc-a9e556fd0be0';
'@ | docker compose exec -T notification-db psql -U lab -d notifications
```

**Вывод по одному запуску:** сбой после локального сохранения заказа и до публикации события оставил заказ без соответствующего уведомления. API перезапустился, но перезапуск не восстановил доставку события. Состояние аварийного заказа и отсутствие уведомления подтверждены пользователем после контрольных запросов; исходные выводы этих запросов отдельно не сохранены. Опыт завершён для демонстрации окна отказа исходной версии. Проведён один запуск; количественные обобщения пока не делаются.
